A self-serve library of firsthand, verified enterprise AI-deployment records — what teams actually did, in the operators' own words, with the receipts. Sourced from YouTube (primary) and first-party writing; delivered decision-ready and personalized by role, for near-zero cost of the user's own tokens.

Purpose

Enterprises distrust AI/vendor claims (94% fact-check them) and want peer evidence. FieldNote does the expensive research once, verifies it, and hands over a short sourced record.

Cheap + trustworthy vs the status quo of costly + unreliable.

Users

  • ConsumerCX/support leader; minimal role profile, self-serve.
  • CuratorRuns the pipeline; performs the SCRUB.
  • AdminRegistry, taxonomy, users, quotas.

Product surfaces

  • Home — hero, workflow entry, featured record, trust strip.
  • Library — search + facets (company·category·models·grade).
  • Record — TL;DR → decision card → evidence.
  • Ask — grounded, cited chatbot.

Ingestion workflow — source-first cascade (cost rises only as confidence rises)

1RegistryCurated channels · podcasts · playlists
2DiscoverYouTube API · metadata only · no LLM
3Cheap GateFree captions + small model: firsthand? CS? fields present?
4ExtractCapable model → schema · quote+timestamp per field
5SCRUBHuman confirms · grades · dedupes
6PublishEntity-resolved · versioned · dated

The record — atomic unit & output contract

Fields: company · industry · workflow · named speaker (firsthand) · source (URL + timestamp) · TL;DR · problem · models · architecture · deployment · outcomes (+ baseline?) · boundaries · fit-to-you · evidence grade · status/versions.

Hard rule: no number, model or claim without a verbatim quote + timestamp. Absent = not_disclosed, shown as such. This rule is the moat.

Evidence grades

AIndependent/production evidence with baseline
BFirst-party + numbers, partial baseline
CDirectional, no baseline / single-source
DAnnouncement / walked-back / conflicted

Metric hygiene: deflection ≠ resolution ≠ containment.

Two token economies

Processing (ours): cascade · free captions · cheap-gate-then-capable-model · cache by video ID · per-record cap.

Consumption (user's): pre-computed, token-free browse. Any AI (the chatbot) runs server-side on our budget, grounded + cited + capped — never metered to the user.

Non-functional & rules

  • No unverified record ships — human SCRUB mandatory.
  • Rights: short excerpt + link + timestamp; never host media (transformative fair use).
  • Freshness: dated + re-review cadence.
  • Reads return fast from pre-computed data.

Scope & stack

In (v1)
  • Customer support: tier-1 deflection · agent-assist
  • Firsthand YouTube + first-party
  • ~40–60 verified records
Out (v1)
  • 1,000 records · other domains
  • X as a record source
  • Vendor case studies / press

Stack: adapt NEO → AWS (Bedrock + Aurora/pgvector); Netlify fallback.
